# Question-Answering-System-using-RAG


## About The Project


The Document Question Answering System is a sophisticated tool designed to streamline information retrieval from vast document collections.

## Library Requirements

 - faiss-cpu
 - langchain-groq
 - PyPDF2
 - langchain_google_genai
 - langchain
 - streamlit
 - python-dotenv




## to run 

   (create virtual environment if needed)
     ```
  1   pip install -r requirements.txt
     ```

     ```
   2  streamlit run app.py
     ```


## API Key Setup

change `.env.example` to `.env` and put the relevant APIs key
